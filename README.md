# work from Programming in C course

The program visualizes a mathematical function in a .ps (PostScript) file. The program input is the mathematical function, the name of the generated file and an optional parameter specifying the range to be rendered.
The math function and other parameters are then validated, and the functions and ranges are tokenized. The function is then converted to reverse Polish notation using a shunting-yard algorithm.
The function is then enumerated in steps and sequentially generated into a file.

in [doc](https://github.com/DanMas03/graph_c/blob/main/doc) folder is Latex code in which the documentation was written.

For more information, see [doc/Dokumentace.pdf](https://github.com/DanMas03/graph_c/blob/main/doc/Dokumentace.pdf).
